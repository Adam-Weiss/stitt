Tibetan Interlinear Translation Tool (TITT) v A.0.1.1

Tibetan source → English, Hebrew, Russian

Technical details

TITT is a local HTML tool for interlinear translation from Tibetan into one or more target languages. Hebrew fields support right-to-left text. Built with HTML, CSS, and JavaScript. Firefox recommended.

Importer instructions

Paste a Tibetan text (Uchen or Wylie) and choose how to split it into blocks. The default splits at double-shad (། །). You can combine options — e.g. double-shad + newline — to handle varied formatting.
