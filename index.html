Tibetan Interlinear Translation Tool (TITT) Version A

One Tibetan source → multiple target languages (English, Hebrew, Russian)

Technical details

TITT is a local HTML tool for interlinear translation from Tibetan into one or more target languages. It provides structured fields for source text, translations, correspondences, and notes. Hebrew fields support right-to-left text.

Built with HTML, CSS, and JavaScript. Open the saved HTML file in any modern browser (Firefox recommended for contenteditable support).

Importer instructions

Paste an ACIP e-text (or any Uchen / Wylie text) into the box above and click Import Tibetan text. The importer splits text at double-shad (། །) boundaries and adds one block per line to the work area.

You can find Tibetan e-texts via the AIBS database or ACIP downloads.

To convert Wylie to Uchen (or vice versa) before importing, use a Tibetan script converter.
